# Инструкции для агентов

## Сборка Flutter

**Важно**: На этом ПК сборка Flutter происходит через WSL2.

- Flutter SDK установлен в WSL2 (Ubuntu)
- Для сборки Android-версии используйте команды через WSL2

### Пример команды для сборки APK:

```bash
wsl -d Ubuntu -- bash -c "cd /mnt/c/Projects/randomdom/flutter_app && flutter build apk"
```

### Альтернативный способ (вход в WSL):

```bash
wsl
cd /mnt/c/Projects/randomdom/flutter_app
flutter build apk
```

## Структура проекта

- `randomdom.py` - основное Python-приложение
- `flutter_app/` - мобильное Flutter-приложение
- `examples/` - примеры конфигураций
